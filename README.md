# Nature’s Harvest — public client design review (temporary)

Responsive, non-transactional visual snapshots of three separate custom WordPress and WooCommerce homepage concepts, together with representative shop/category views.

- Market Day: https://digipixel-uk.github.io/client-natures-harvest-previews/market-day/
- The Larder: https://digipixel-uk.github.io/client-natures-harvest-previews/the-larder/
- The Fresh Edit: https://digipixel-uk.github.io/client-natures-harvest-previews/fresh-edit/

No backend, payment method, WordPress login, live stock, orders, customer information or checkout functionality is published here. The demo catalogue, prices, photographs and delivery coverage are placeholders, not confirmed shop listings. Pages carry noindex metadata and a review-only notice.

The canonical private WordPress + WooCommerce source is digipixel-uk/client-natures-harvest-website. This is an interim, external GitHub Pages fallback, not the requested dedicated staging deployment. The existing staging SSH identity mismatch must be verified before use. The public review is independent of production or the private WordPress database.
